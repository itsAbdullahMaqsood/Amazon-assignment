For each line, load the product, find the size row matching `p.size` inside `subProducts[p.style]`, and return the line merged with fresh values: `priceBefore` (the original price), `price` (discount applied, 2dp, Number), `quantity` (that size's stock) and `shippingFee` (the product's shipping). Respond with the array. Never trust the client's price.

POST /api/user/savecart — body { cart }. Delete any existing Cart document for this user, then rebuild the lines server-side: for each item load the product, take `subProducts[item.style]`, and store { product: dbProduct._id, name, image: subProduct.images[0].url, size: item.size, qty: Number(item.qty), color: { color, image }, price } where price is the database price with the variant discount applied to 2dp. Sum `cartTotal` from those server-side prices, save one new Cart for the user, and respond `{ message: "cart Items succesfully added.", status: true }`. The checkout page reads this Cart document, so the client's numbers must never reach the database.

Put the client-side callers in request/users.ts alongside the existing helpers, matching whatever HTTP client the project already uses in its other client components.
